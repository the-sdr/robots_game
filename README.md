# Robots

An exploration game built in Godot 4.

## Current vision

- Start inside a small house, wake up next to a charging station
- Step outside into a dense, overgrown garden — the trees and old ruined
  walls themselves form a maze, not a separate area
- Find the one way through
- Crest a hill and see a ruined city revealed beyond

## Technology

- Godot 4.7 (GDScript)
- Jolt Physics
- Art: Quaternius CC0 asset packs (Stylized Nature MegaKit, Medieval Village
  MegaKit, Downtown City MegaKit, Ultimate Textured Building Pack)

## Running the project

Open `project.godot` in the Godot editor and press Play. The main scene is
`scenes/world.tscn`.
